# 📅 Дневник планов

Ежедневный трекер: план → факт → заметки.
Коммить сюда каждый день, чтобы обновлять запись — это и держит граф контрибуций зелёным.

---

## Как пользоваться

1. Каждый день добавляй новый блок в раздел **Записи** (сверху, самые свежие — первыми).
2. Отмечай пункты `- [ ]` → `- [x]`, когда сделано.
3. Коммить с понятным сообщением, например: `2026-08-25: план на день`.
4. Если хочешь, чтобы контрибуции были видны в графе, но содержимое — нет:
   держи репозиторий **приватным** и включи в настройках профиля
   `Settings → Contributions → Include private contributions on my profile`.
